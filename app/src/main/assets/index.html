About this build

Mithu YouTube Agent 1.1.0

এই build-এ Settings page, upload mode switch ও local preferences সংরক্ষণ কাজ করে। AI generation, TTS, video rendering এবং YouTube OAuth/upload এখনো সংযুক্ত নয়।

API Key স্থানীয় WebView storage-এ plaintext হিসেবে থাকে। Production ব্যবহারের আগে Android Keystore-backed secure storage বা trusted backend যোগ করতে হবে।
